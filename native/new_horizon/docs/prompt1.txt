### Relevant Context for this task
1. We generate horizons for the inner digital elevation map in a nested list of DEMs
2. By convention, we generate horizons for this inner DEM one 128 x 128 pixel square region at a time.  These are written into files.
3. The horizon file name is generated by the BuildDefaultFileName method of the QuadTreeHorizonGenerator class.
4. These files contain data for 128 x 128 horizons, each involving 1440 elevation angles

### Requirements for this Task

1. Design an algorithm that generates horizon files for all 128 x 128 pixel patches within a DEM surrounded by additional DEMs.
   a. Assume the DEM dimensions are even multiples of 128. Throw an exception if this input assumption is violated.
   b. Write the files into a specified directory.
2. Look at the primary GenerateHorizons method of the QuadTreeHorizonGenerator class on line 322 of the file for how to generate a horizon file.
   a. Note the sequence of tasks involved: load the ElevationMaps, generate the tile trees for the elevation maps, then process a sequence of 128 by 128 pixel patch of the inner DEM, writing a file containing the horizons for the patch.
   b. Processing a patch involves generating the polynomials describing the rays then launching a kernel for each DEM, then a kernel that combines them.
3. An efficient algorithm for generating horizons for a large number of patches would pipeline the stages and overlap CPU and GPU work.
   a. Design an algorithm to do this and write a detailed description of it.
   b. Then add this code to the QuadTreeHorizonGenerator class.  You can refactor that class if you wish. The existing entries must still exist, but they can be refactored to use the pipeline you design.
4. If you have questions about this task, ask them first.
